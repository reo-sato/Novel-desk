Novel Desk 使い方
==================

■ 起動
1. このフォルダ（novel-desk）を好きな場所に置く（例：ドキュメント）
2. 「start.bat」をダブルクリック
3. ブラウザが自動で開きます（開かなければ http://127.0.0.1:8010 を開く）

※黒い画面は Novel Desk 本体です。使っている間は閉じないでください。
※黒い画面の中をクリックすると止まることがあります。その時は Esc キーで再開。
※SillyTavern（8000番）と同時に起動しても大丈夫です。

■ 最初の設定（1回だけ）
右上の「⚙ 接続設定」を開いて
・Featherless の APIキー
・モデルID（例：huihui-ai/Huihui-gemma-4-31B-it-abliterated-v2）
を入れて「閉じる」。

■ 書き方の流れ
1. 左の「作品設定」を埋める
   ・文体・書き方のルール … 毎回守らせたいこと（視点、文体、禁止事項など）
   ・登場人物 … 名前・年齢・容姿・性格・口調・一人称。ここは変えさせません
2. 「構成案を作る」で場面構成を作らせる（自分で書いてもOK）
3. 下の欄に「次の場面で書くこと」と分量（字）を入れて「次の場面を書く」
   （Ctrl+Enter でも実行できます）
4. 場面ごとに 3 を繰り返す → 合計で長編になります

■ ボタン
・続きを書く … 途中で切れたとき、最後の文の続きから書き継ぐ
・書き直す … 直前に書いた部分を消して、同じ指示でもう一度
・取り消し … 直前の生成をなかったことにする
・停止 … 生成を途中で止める
・本文から要約を作る … 本文が1万字を超えてきたら押す。
  長い本文は前半をモデルに渡せないので、要約で話の流れを覚えさせます

■ 分量（字数）について
・作品全体の字数 … 「作品設定」の「作品全体の目標字数」に入れると、あと何字か表示されます
・1回に書かせる量 … 本文タブの「分量の目安」で決めます
・モデルは字数を数えられないので、ツール側で数えて調整します
  - 足りなければ、同じ場面を自動で書き足します（最大5回）
  - 目安を超えたら、段落の切れ目で止めます
  （「⚙ 接続設定」の「分量の目安に合わせる」で切り替えできます）
・「文体・書き方のルール」には字数を書かないでください。1回分の目安と混ざって、モデルが迷います
・モデルが同じ文を繰り返し始めたら、自動で止めて繰り返し部分を消します

■ 文体を整える（お手本・避けたい表現・推敲）
・作品設定の「文体のお手本」… 目指す書き方の実例を1000〜2000字貼ると、いちばん効きます。
  自分の文章や、生成文を好みに直したものがおすすめ（内容は使わず、書き方だけ真似させます）
・作品設定タブの一番下「避けたい表現」… 1行に1つ。「まるで〜よう」のように「〜」で間を省略できます。
  本文の上の「文体チェック ○件」を押すと一覧が出て、タップでその場所に飛べます
・「推敲する」ボタン … 直前に書いた部分を「推敲のチェック項目」に沿って書き直させ、
  推敲前と見比べてから「採用する」で反映します。本文の一部を選択してから押すと、その部分だけ推敲します
・「場面を書いたあと、自動で推敲する」にチェックを入れると、毎回自動で推敲します
  （「取り消し」1回で推敲前、2回で場面を書く前に戻ります）
・「⚙ 接続設定」の min_p（0.05目安）を入れると、変な比喩や言葉選びが減りやすくなります

■ アップデート
・新しいバージョンが出ると、「⚙」ボタンに ● が付きます
・「⚙ 接続設定」の一番下「アップデート」→「アップデートする」で更新し、自動で再起動します
・書いた作品と設定（data フォルダ）はそのまま残ります。以前のファイルは data/old-version-○○ に保存されます
・start.bat / start-lan.bat は更新されません（変更が必要なときは画面でお知らせします）

■ コツ
・1場面2000〜3000字くらいで区切ると、内容が濃くなりやすいです
・キャラがぶれたら「登場人物」欄をより具体的に（口調の例文を書くと効きます）
・本文は直接書き換えてOK。気に入らない文を消してから「次の場面」で進められます
・モデルを変えたいときは「接続設定」のモデルIDを差し替えるだけ

■ スマホから使う（家の同じWi-Fiだけ）
1. PCで start.bat の黒い画面が開いていたら閉じる
2. 「start-lan.bat」をダブルクリック
   → 初回はWindowsのファイアウォールの確認が出るので
     「プライベート ネットワーク」にチェックして「許可」
3. PCで開いた画面の「⚙ 接続設定」→ 一番下「スマホから使う」で
   パスワード（6文字以上）を設定
4. 同じ欄に出ている http://192.168.○.○:8010/ のアドレスを、
   スマホ（同じWi-Fiにつなぐ）のブラウザで開く
5. パスワードを入れてログイン（1年間はログインしたままになります）

・スマホでは画面上の「本文」「作品設定」のタブで切り替えます
・使っている間はPCをつけたまま、黒い画面も開いたままにしてください
・生成中にスマホの画面を消すと、途中で止まることがあります
・PCとスマホは数秒おきに自動で同じ内容にそろいます。
  別々の項目を同時に書き換えても、両方とも残ります
  （同じ項目を同時に書き換えたときは、後から保存した方が残ります）
・APIキーはPCのファイルにだけ保存され、スマホには送られません
・スマホで開けないとき：
  - スマホが同じWi-Fiにつながっているか（モバイル通信だと開けません）
  - アドレスの数字が変わっていないか（PCの「接続設定」で確認できます）
  - ファイアウォールで許可したか
    （「Windows セキュリティ」→「ファイアウォールとネットワーク保護」
      →「ファイアウォールによるアプリケーションの許可」で Node.js を許可）
・パスワードを忘れたら、PCの「接続設定」から設定し直せばOK

■ 保存
・自動で data フォルダの novel-desk.json に保存されます（1つ前の状態は backup も残ります）
・本文は「書き出し・読み込み」→「本文をテキスト(.txt)で保存」で取り出せます
・フォルダごとコピーすれば丸ごとバックアップになります

■ 必要なもの
Node.js 18 以上（SillyTavern を動かせているなら入っています）
